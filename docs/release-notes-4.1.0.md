# V4.1.0 说明

## 本版做了什么

**界面重构（UI 试验包已先行验证）**
- 首页：头像进入管理页、森林卡片直接收能量、Hero 自定义裁切、卡片背景换图、底部导航真实模糊。
- 计划：任务组（日常）成为一等公民——选任务 → 命名 → 开始时间 → 保存为一组；计划页按组展示，
  可展开看成员、单条立即执行；组支持编辑、复制、删除。
- 配置：重排为「账号与设备 / 总开关 / AI / 运行策略 / 通知与系统 / 高级与工具」。
  总开关关闭只停自动化，不动计划与 1009 冷却；开启只解除手动暂停。
- 数据（原日志）：今日指标、近 14 天完成度热力图、每域耗时中位数、AI 摘要；
  技术日志与诊断导出保留在下方；配置文件与备份恢复挪入「数据管理」。
- 好友：真实好友名册（注入层导出）、森林/庄园 PK 名单、常用名单（各域选好友可只看常用）。
- 开源致谢：上游与直接依赖清单、自有代码占比（数据页同源统计）。

**上游 Sesame-M 1.5.3 合并**
- 会员任务：任务与广告拆分取数、减少重复请求、风控下不反复请求。
- 果园：多阶段任务按剩余次数推满，不再只完成首阶段。
- 森林：新版保护地（多区域遍历、证书兑换）、动物伙伴派遣、保护罩续用、组队合种切换、无纸阅读凭证。
- 其余域：待办/海洋/运动/摊位/绿色金融/保护生态/阅读答题的防御性解析；失败应答进异常日志。
- 本地按任务/按段过滤闸门全部保留。

## 升级与兼容

- 宿主与模块必须成对升级；本版宿主基于支付宝 10.8.30.8000 重新 npatch。
- 版本号：模块与宿主 V4.1.0（versionCode 41000）。
- 配置、计划、账本、风控状态沿用原目录，升级不迁移数据。

## 已知限制

- 一键加好友尚未实现：宿主只做只读能力探测（friend_capability_probe.json），不发请求。
- 人工操作用时（B 组基线）未接入数据页，当前耗时为自动运行统计。
- 6 天观察期自 2026-10-29 起算，旧 4 天数据仅作对照，不与本版混算。
