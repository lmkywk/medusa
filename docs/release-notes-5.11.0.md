# V5.11.0 公开版

## 本版改动

- **数据目录改为 Medusa**：`/sdcard/Android/media/com.eg.android.AlipayGphone/Medusa`。
  首次启动自动从旧 `sesame-M` 复制配置/账本/计划/统计/AI 数据；旧目录保留不删；旧日志不迁移（可能上百 MB）。
- **新装默认关闭**：新装/新账号的任务与域开关默认全部关闭；日志、通知、权限等基础设施保持默认；
  已有配置不会被重置。
- **API 101 兼容**：模块改为 libxposed API 101 编译，同一个包可在 FPA 101 与 LSPosed/Vector 102 上加载。
- **AI 分析页保存修复**：保存失败不再提示“已保存”；返回页面自动保存未提交的接口/令牌改动；
  令牌弹窗“保存”改为“确定”，避免误解为已落盘。
- **域设置保存修复**：点击保存强制写盘并提示“已保存”；写盘失败会显示具体原因，不再吞掉失败。
- **AI 摘要校验修复**：否定句（如“不执行领取”“不自动执行”）不再被误判为可执行意图；
  历史上被误杀的摘要会在打开时用新规则重校验并恢复为可读文本。

## 未改动

- 1009/1004 风控处理、全局暂停、计划执行与补跑/离线逻辑保持不变。
- 闹钟健康状态页的跨天误报暂未处理。

## 安装

- 模块 APK：`美杜莎_V5.11.0_模块_arm64.apk` / `_universal.apk`
- 宿主需与模块成对安装；宿主 APK 不随仓库分发。
- 数据备份：`Medusa/config/<uid>/plans.json`、`config_v2.json`、`risk_state.json`、`ledger/`。
